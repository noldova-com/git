# @noldova/git.window

The Git module's window part, in Angular: the Git view of a folder's branch, changes and commit.
It is compiled by Angular's compiler in partial compilation mode; Angular, Noldova Desktop's and context's packages and the interface kit are optional peers, which the app's window workspace provides.

An app reaches its API through [`@noldova/git`](https://github.com/noldova-com/git/tree/main/src/noldova.git)'s `./window` export, and the module pins it at its own version.
[documents/ARCHITECTURE.md](https://github.com/noldova-com/git/blob/main/documents/ARCHITECTURE.md) says how it is built, and the [README](https://github.com/noldova-com/git#readme) how to build and test it.
