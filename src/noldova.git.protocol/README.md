# @noldova/git.protocol

The messages the Git module's runtime and window parts exchange, with their JSON forms and their checks: a folder's status, diffs, branches, worktrees and the protocol's failures.

Both parts of [`@noldova/git`](https://github.com/noldova-com/git/tree/main/src/noldova.git) import it by its name, and the module pins it at its own version.
[documents/ARCHITECTURE.md](https://github.com/noldova-com/git/blob/main/documents/ARCHITECTURE.md) says how the parts talk, and the [README](https://github.com/noldova-com/git#readme) how to build and test it.
